# Loci Privacy

Loci 是一个本地优先的 Chrome 新标签页扩展。它读取你的浏览器书签并在新标签页中显示为图视图。

## 数据使用

扩展会在本机使用以下 Chrome API：

- `bookmarks`：读取、创建、编辑、移动和删除 Chrome 书签及文件夹。
- `history`：读取最近访问记录，用于计算书签节点权重和最近访问列表。
- `topSites`：在没有书签可显示时，读取常用站点作为空状态兜底。
- `storage`：保存图连线、固定节点位置、显示设置、待办、所选天气城市及天气缓存。
- `activeTab`：用户点击工具栏中的 Loci 扩展按钮时，读取当前网页标题和 URL，用于预填收藏表单。不会读取网页正文或后台批量采集标签页。

## 数据存储

扩展数据保存在 Chrome 本机能力中：

- Chrome 书签仍保存在 Chrome 自己的书签系统里。
- 图连线、图钉、设置、待办、所选天气城市及天气缓存保存在 `chrome.storage.local`。
- 新增的时间、天气、待办小组件默认关闭；日期继续显示。待办内容仅保存在本机，多个新标签页共享本机数据。
- 开发模式下，如果没有 Chrome 扩展 API，会使用浏览器 `localStorage` 存 mock 数据。
- 收件箱使用 Chrome 中的独立书签文件夹；其实际 ID 和最近一次收藏的随机请求 ID、书签 ID 保存在 `chrome.storage.local`，用于识别位置及防止重复提交。收藏标题、完整 URL 和归档位置写入 Chrome 书签系统。

## 数据传输

数据是否发送到外部服务取决于用户主动启用的功能：

- **快速收藏与手动归档**：通过 Chrome 本机书签 API 保存或移动，不调用 AI 或其他远程收藏服务。Chrome 自身的书签同步取决于用户的浏览器账号设置。
- **AI 主题分析与整理**：用户配置模型服务并手动触发后，扩展会向所选服务商发送书签 ID、标题和域名；整理还会发送当前分组名称及可复用分组名称。正常网页的完整 URL 路径、查询参数、浏览历史、待办和天气数据不用于这些请求。API Key 保存在本机，用于向所选服务商认证。生成方案后，只有用户应用方案才会移动书签。
- **收件箱的所选整理**：仅发送用户选中的可写书签 ID、标题、域名与当前分组名称，以及用于复用的可写分组名称；不会附带未选中书签的标题或 URL。进入配置界面不会自动发起 AI 请求。
- **天气**：用户主动启用并选择城市后，扩展会连接 Open-Meteo（`geocoding-api.open-meteo.com` 与 `api.open-meteo.com`）。城市搜索发送输入的城市文字；预报请求发送所选城市坐标、温度单位和天气字段。服务端会接收到常规网络连接信息，例如 IP 地址。扩展不会自动定位，也不会向天气服务发送书签、浏览历史、待办或 AI Key。
- **天气更新**：本机缓存天气结果，在页面可见且缓存过期时刷新；关闭天气会停止该页面的后续天气请求。服务权限被撤回后，天气查询停止，其他功能仍可使用。
- **外部搜索**：用户确认搜索或提问后，会打开所选搜索引擎或服务商的页面，并将输入词包含在目标链接中。

天气服务说明：[Open-Meteo](https://open-meteo.com/)。模型服务的数据处理方式以用户所选服务商的政策为准。

扩展会尝试加载站点 favicon。浏览器可能会向对应网站请求图标资源，这和打开该网站图标的常规网络行为一致。

## Chrome Web Store Limited Use 声明

扩展仅将通过 Chrome API 获得的信息用于提供和改进“书签图谱新标签页”这一单一用途。扩展不会出售用户数据，不会将用户数据用于广告，不会将用户数据转移给数据经纪商或广告平台，也不会将用户数据用于信用评估或借贷目的。

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## 用户控制

你可以随时：

- 在 Chrome 扩展管理页禁用或卸载扩展。
- 在扩展里删除由它创建的书签、分组、连线和图钉。
- 在“设置 → 小组件”关闭天气或待办，切换天气城市；删除待办后可短时撤销。关闭组件会保留本机设置和数据。
- 在 Chrome 扩展管理页撤回天气服务的可选网站权限。
- 在 Chrome 书签管理器中继续管理同一批书签，扩展会跟随刷新。

## 权限变更

天气仅声明 Open-Meteo 两个域名的可选网站权限，在用户开启天气时请求。后续若新增网络同步、账号登录或其他远程服务，会同步更新隐私说明、功能告知和所需权限。

快速收藏新增 `activeTab` 权限，由用户点击扩展按钮触发临时访问；未申请持续读取全部标签页的 `tabs` 权限，也未注入网页内容脚本。权限机制参考 [Chrome activeTab 文档](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)。
