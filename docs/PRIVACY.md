# Loci Privacy

更新日期：2026-10-12 · 适用范围：当前源代码版本

Loci 是一个本地优先的 Chrome 新标签页扩展。它读取你的浏览器书签并在新标签页中显示为图视图。

## 数据使用

扩展会在本机使用以下 Chrome API：

- `bookmarks`：读取、创建、编辑、移动和删除 Chrome 书签及文件夹。
- `history`：读取最近访问记录，用于计算书签节点权重和最近访问列表。
- `topSites`：在没有书签可显示时，读取常用站点作为空状态兜底。
- `storage`：保存图连线、固定节点位置、显示设置、小组件位置和尺寸、待办、便签、专注计时、收藏回访偏好、AI 执行历史、所选天气城市及天气和行情缓存。
- `geolocation`：仅在用户点击「使用当前位置」后读取一次设备位置，用于识别天气城市；不在页面加载、天气刷新或后台持续定位。

## 数据存储

扩展数据保存在 Chrome 本机能力中：

- Chrome 书签仍保存在 Chrome 自己的书签系统里。
- 图连线、图钉、设置、待办、便签、专注计时状态、收藏回访偏好、所选天气城市、天气与行情缓存、图片引用和图标缓存偏好保存在 `chrome.storage.local`。
- 上传壁纸、最近一张必应壁纸，以及用户启用的网站图标缓存以 Blob 存储在扩展来源的 IndexedDB 中。旧 Base64 壁纸会自动迁移；写入成功后才替换原引用，迁移失败保留原记录。未被当前设置或壁纸收藏引用的旧上传图片会在保留至少一天后清理。
- 便签仅在本机自动保存；点击复制时写入系统剪贴板，选择转为待办时在本机创建待办。专注计时保存时长、剩余时间、结束时间与关联待办 ID；关闭全部新标签页后不发送系统通知。
- 收藏回访在本机从书签中挑选内容，保存回访范围与当天跳过的书签 ID；不会自动打开或上传所选书签。
- 行情设置中的 Tushare Token、关注代码和显示偏好保存在本机；Token 用于向 Tushare 认证，不会发送给 AI 或天气服务。行情和交易日缓存按 Token 的 SHA-256 摘要区分；原始 Token 仍保存在本机设置中，并非加密保险箱。
- AI 执行历史在本机保存整理或分析的时间、模型、书签标题和域名、分组去向及操作结果，最多保留 50 条并限制整体大小约 2 MB；不记录 API Key。旧记录会随保留上限自动淘汰，当前版本没有单独清空历史的界面。
- 时钟、天气、待办小组件默认关闭；日历默认开启，可单独关闭。卡片位置、尺寸、外观和开关保存在本机。待办内容仅保存在本机，多个新标签页共享本机数据。
- 日历小组件使用本机日期、浏览器内置农历与扩展内置的年度放假安排，离线运行，不请求外部日历或个人日程权限。只有主动点击官方来源链接才会访问对应网站。
- 开发模式下，如果没有 Chrome 扩展 API，会使用浏览器 `localStorage` 存 mock 数据。

## 数据传输

数据是否发送到外部服务取决于用户主动启用的功能：

- **AI 主题分析与整理**：用户配置模型服务并手动触发后，扩展会向所选服务商发送书签 ID、标题和域名；整理还会发送当前分组名称及可复用分组名称。正常网页的完整 URL 路径、查询参数、浏览历史、待办和天气数据不用于这些请求。API Key 保存在本机，用于向所选服务商认证。生成方案后，只有用户应用方案才会移动书签。
- **天气**：用户主动启用并选择城市后，扩展会连接 Open-Meteo（`geocoding-api.open-meteo.com` 与 `api.open-meteo.com`）。城市搜索发送输入的城市文字；预报请求发送所选城市坐标、温度单位和天气字段。服务端会接收到常规网络连接信息，例如 IP 地址。扩展不会向天气服务发送书签、浏览历史、待办或 AI Key。
- **可选定位操作**：点击「使用当前位置」后，扩展申请 BigDataCloud 域名访问权限，通过浏览器定位 API 获取一次当前位置，并直接发送到 `api.bigdatacloud.net` 识别城市。服务方会接收坐标和 IP，其说明表示会利用匿名位置与 IP 配对改进地理位置数据。Loci 不保存此次精确坐标，仅保存城市与保留两位小数的约略坐标，之后的天气查询使用约略坐标。拒绝定位后不会改用 IP 推断城市；可以继续手动搜索。关闭城市选择器或改为输入搜索会丢弃未完成的定位结果。
- **天气更新**：本机缓存天气结果，在页面可见且缓存过期时刷新；关闭天气会停止该页面的后续天气请求。服务权限被撤回后，天气查询停止，其他功能仍可使用。
- **市场速览**：用户主动连接 Tushare 并授权 `https://api.tushare.pro/*` 后，行情请求会向 Tushare 发送 Token、查询的指数或股票代码、日期与字段；服务方还会收到 IP 等常规连接信息。连接测试会使用 Token 请求指数数据。功能用于显示行情和交易状态，不读取证券账户、持仓或交易记录，也不执行交易。不会向 Tushare 发送书签、浏览历史、便签、待办或 AI Key。接口权限、调用额度与费用由用户的 Tushare 账号决定。
- **便签、专注与收藏回访**：这些功能的处理在本机完成，不调用远程分析服务。主动点击回访书签后，浏览器会访问该目标网站。
- **Bing 每日壁纸**：用户在壁纸设置中开启并授权后，扩展连接 `cn.bing.com` 与 `www.bing.com` 获取每日图片元数据和图片。请求不携带浏览器 Cookie、书签、浏览历史、天气位置或 API Key；服务会收到 IP 等常规连接信息。仅缓存最近一张图片与署名、来源、更新日期，页面可见时定期检查更新，断网保留已缓存图片。关闭此壁纸或撤回网站权限后不再下载新图片。
- **外部搜索**：用户确认搜索或提问后，会打开所选搜索引擎或服务商的页面，并将输入词包含在目标链接中。

天气服务说明：[Open-Meteo](https://open-meteo.com/)。城市定位说明：[BigDataCloud 客户端城市识别与数据使用](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)。模型服务的数据处理方式以用户所选服务商的政策为准。

扩展通过 Google 的 `t0.gstatic.cn/faviconV2` 图片服务加载网站 favicon。请求只包含书签网址的公开主机名，不包含路径、查询参数、片段、端口或账户信息；本机名称、局域网名称和 IP 地址会跳过。服务会收到域名与 IP 等常规网络信息，不会收到书签标题、完整网址或浏览历史。无法加载时显示首字母，不再向目标网站请求 `/favicon.ico`。

图标的本机持久缓存默认关闭。用户在“设置 → 通用”开启并授权后，扩展通过 `https://t0.gstatic.cn/*` 下载图标并以 Blob 保存，不携带 Cookie 或 Referer。缓存记录只保存公开网站域名、图片与缓存/使用时间；可选择 7、30 或 90 天更新间隔和 5、20 或 50 MB 容量，最多保存 2,000 个网站，超限优先清理较少使用的图标。过期后连接失败会保留旧图标。关闭后不再读写持久图标缓存，仍按原方式在线加载；可单独清空已存图片，已显示的图标会保留到本页关闭。

## Chrome Web Store Limited Use 声明

扩展仅将通过 Chrome API 获得的信息用于提供和改进“书签图谱新标签页”这一单一用途。扩展不会出售用户数据，不会将用户数据用于广告，不会将用户数据转移给数据经纪商或广告平台，也不会将用户数据用于信用评估或借贷目的。

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## 用户控制

你可以随时：

- 在 Chrome 扩展管理页禁用或卸载扩展。
- 在扩展里删除由它创建的书签、分组、连线和图钉。
- 在“设置 → 小组件”关闭天气或待办，切换天气城市；删除待办后可短时撤销。关闭组件会保留本机设置和数据。
- 在 Chrome 扩展管理页撤回天气服务的可选网站权限。
- 在“设置 → 壁纸”关闭 Bing 每日壁纸或选择其他壁纸；也可撤回必应的可选网站权限。关闭后保留最近一张本机缓存。
- 在小组件设置中关闭便签、专注、收藏回访或市场速览；关闭会保留本机数据。可清空便签、重置计时、调整回访范围，或在行情设置中点击「断开连接」清除 Token、修改关注列表，并在 Chrome 扩展管理页撤回 Tushare 的可选网站权限。
- 不使用「使用当前位置」，或撤回 BigDataCloud 可选网站权限，继续通过手动城市搜索使用天气；浏览器和操作系统的定位限制仍然有效。
- 在 Chrome 书签管理器中继续管理同一批书签，扩展会跟随刷新。

## 权限变更

Open-Meteo 两个域名是可选网站权限，在用户开启天气时请求；BigDataCloud 域名单独在点击定位按钮时请求。Chrome 不支持将 `geolocation` 声明为可选扩展权限，因此本版本在 manifest 中声明该权限，但代码仅在用户主动点击时调用定位 API。更新安装可能需要重新确认新增权限。参考 [Chrome 权限说明](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

工具栏收藏弹窗与专用收件箱入口已移除，当前版本不再申请 `activeTab` 权限。旧版本创建的 Chrome 书签与文件夹会保留。

Tushare 域名为可选网站权限，仅在用户主动连接行情服务时申请。便签、专注与收藏回访无需新增权限。

必应的 `https://cn.bing.com/*` 和 `https://www.bing.com/*` 为可选网站权限，仅在用户开启 Bing 每日壁纸时申请，用于读取每日图片信息及下载壁纸。

图标服务 `https://t0.gstatic.cn/*` 为可选网站权限，仅在用户开启图标缓存时申请；用于下载并在本机缓存图标。新增 Blob 存储本身不需要额外权限，也未申请 `unlimitedStorage`。
