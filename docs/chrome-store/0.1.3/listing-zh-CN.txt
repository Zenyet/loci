名称
Loci

简短说明（可直接粘贴）
把 Chrome 书签变成可探索的图谱新标签页，快速搜索、整理收藏，并按需添加便签、待办与专注计时。

详细说明（从下一行开始复制）
让收藏的内容，重新回到你的视线里。

Loci 将 Chrome 新标签页变成一个书签图谱。沿着文件夹探索收藏，搜索想找的网站，把暂时来不及整理的页面放进收件箱，再慢慢归档。

探索你的书签
• 在可缩放、可拖动的图谱中浏览书签和文件夹。
• 点击文件夹进入分组，点击书签打开网站。
• 按标题、网址或分组快速搜索；支持 Ctrl / ⌘ + K 唤起搜索。
• 创建、编辑和移动书签，与 Chrome 自带书签系统保持一致。
• 从新标签页查看常用站点和最近访问。

随手收藏，稍后整理
• 点击浏览器工具栏中的 Loci 按钮，保存当前页面。
• 先存入收件箱，再手动归档到合适的文件夹。
• 可选 AI 整理：使用自己的模型服务与 API Key，先预览整理方案，再决定是否应用。

让新标签页更顺手
• 日期与日历：查看农历、节日，以及已内置的中国大陆 2026 年放假和调休安排。
• 待办与便签：记下接下来要做的事，把便签内容转为待办。
• 专注计时：设定一段专注时间，也可以关联待办。
• 收藏回访：从已有收藏中重新发现值得阅读的内容。
• 可选天气：手动选城市，或主动使用当前位置。
• 可选市场速览：连接自己的 Tushare 账号，查看支持的 A 股指数和沪深个股行情。
• 自定义壁纸、外观和小组件；首页最多固定 3 个工具。

本地优先，按需连接
核心书签功能无需注册 Loci 账号。设置、待办、便签和计时状态保存在本机；书签继续使用 Chrome 自己的书签系统，同步取决于 Chrome 账号设置。

AI、天气和行情均为可选功能。AI 需要自行配置服务与 API Key；运行时会向所选模型服务发送相应书签的标题、域名等整理所需数据。天气使用 Open-Meteo，主动定位时使用 BigDataCloud。行情需要自备 Tushare Token，并开通相应接口权限；第三方服务可能有独立额度或费用。Loci 不提供证券交易功能。
