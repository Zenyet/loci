Loci 0.1.3

相对仓库 0.1.2 的变更
• 设置面板统一使用关闭按钮，去掉左上角的红色圆点。
• 保留原有文件夹造型。
• 修复搜索等列表中的网站图标加载成功后仍超时重试、最终显示空白的问题。
• 补充便签、专注、收藏回访和市场速览的数据使用说明。
• 同步扩展与项目版本号，更新商店介绍与发布素材。

说明
此更新说明以仓库上一版本为基准，尚未核对 Chrome 商店当前已发布版本。不要把它当作已核验的线上版本差异。
