## 更新方式

1. 使用 `npm run dev` 启动项目，在独立的预览浏览器环境中打开终端提供的本地地址。
2. 使用内置示例书签与不含个人信息的演示内容，通过实际界面进入需要展示的功能。
3. 等待图片、图标与在线数据加载完成，再截取应用视口；保持同一组图片尺寸一致。
4. 保留第三方内容署名。AI 和行情没有可用凭据时展示配置状态，不伪造执行结果。
5. 替换同名图片，检查根目录 README 的引用、图片内容与说明是否对应，并更新截图日期。
