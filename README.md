# Loci

Chrome 扩展（Manifest V3），替换新标签页，把真实 Chrome 书签变成一张可搜索、可编辑、可聚焦的图谱。

产品规划见 [书签效率与日常小组件迭代计划](docs/plans/2026-09-18-product-roadmap.md)（历史规划；当前入口与功能以本页为准）。

## 现在的交互模型

- 首页显示书签栏的顶层分组与直属书签，以及“其他书签”、移动设备等来源入口；右键空白可筛选来源。受管理目录只读。
- 点击分组节点会进入该分组，子分组和直接书签会在当前层级里散开。
- 点击书签节点会打开书签。
- 搜索支持多关键词，优先匹配标题并展示全部结果；选中结果时，图会切到匹配节点所在层级并平滑跟随聚焦。
- 右键空白可添加书签或新建分组；添加书签默认落在当前层级，首页添加就是 Chrome 书签栏直属书签。
- 右键空白 → 分组管理，可重命名、删除、移动分组并调整分组色调。
- 小组件默认采用紧凑尺寸，沿视窗外侧摆放，为中央书签图谱留出空间。右上角小组件按钮进入桌面编辑：自由拖动卡片、方向键微调、选择小/中/大尺寸；布局保存在本机。设置 → 小组件提供卡片图库，可分别启用各工具，并选择浅色、深色、染色或跟随系统外观。
- 天气与日历分别显示为圆角卡片。天气支持逐小时预报、手动搜索城市、一次性定位、摄氏/华氏、缓存和离线提示。
- 日历保留月历、农历、传统节日、放假与补班标记。当前收录中国大陆 2026 年官方放假安排，其他年份显示待更新；设置可分别隐藏农历与放假安排。支持方向键、Home/End、Page Up/Down 选日期和切月份。
- 其他卡片包括时钟、今日待办、本地便签（选中文字转待办）、可关联待办的专注计时、每日收藏回访，以及需自备 Tushare Token 并授权连接的市场速览。可分别添加、移除和摆放，不再限制固定卡片数量。
- 设置 → 壁纸可开启 Bing 每日壁纸，授权后自动检查当天图片，保留摄影署名；离线时继续显示最近成功缓存的图片。国内线路失败会自动尝试必应备用线路；权限缺失可点击“授权并重试”。
- 上传壁纸与 Bing 图片以 Blob 保存在 IndexedDB，设置和壁纸收藏只记录图片 ID；同一张上传图片不会重复存储。旧 Base64 壁纸会自动迁移，失败时保留原记录。
- 设置 → 通用 → 网站图标缓存，可开启本机 Blob 缓存（默认关闭），选择 7/30/90 天更新间隔、5/20/50 MB 容量，并查看占用或清空缓存。超限按最近使用情况清理；离线时优先使用旧缓存。
- 网站图标统一通过 `t0.gstatic.cn/faviconV2` 获取，仅发送公开网站域名，失败时显示首字母；不请求网站的 `/favicon.ico`，本机及 IP 地址不会发送给图标服务。
- 设置 → 智能整理，配置模型服务、测试连接，再预览 AI 分组方案、应用或撤销整理。
- 小组件直接显示内容；待办、便签、专注和收藏回访在卡片内操作，不再点击整卡打开弹框。城市、计时设置、回访范围及便签转待办等功能在设置 → 小组件中配置。

## Chrome 联动

扩展直接读写 Chrome 本机 API：

- `chrome.bookmarks`：读取书签树；创建、编辑、移动、删除书签和文件夹；监听外部变化并刷新图。
- `chrome.history`：聚合近 30 天访问频次，用于节点权重。
- `chrome.topSites`：当书签为空时，用常用站点做轻量兜底。
- `chrome.storage.local`：保存图连线、图钉位置、设置、待办与天气缓存。

开发模式下没有 Chrome 扩展 API，会自动使用 localStorage mock 数据；安装到 Chrome 后才会接真实书签。

## 常用操作

| 操作 | 入口 |
| ---- | ---- |
| 进入分组 | 点击分组节点 |
| 返回上级 | 顶部当前分组旁的返回按钮 |
| 打开书签 | 点击书签节点 |
| 搜索/聚焦 | 直接输入、`⌘ / Ctrl K`，或右上角搜索按钮 |
| 添加书签 | 右键空白 → 添加书签 |
| 小组件 | 右上角小组件按钮，或设置 → 小组件 |
| 新建分组 | 右键空白 → 新建分组 |
| 分组管理 | 右键空白 → 分组管理 |
| 编辑/删除书签 | 右键书签节点 |
| 建立关联 | `Shift` + 拖书签节点到另一个书签节点 |
| 删除关联 | 右键连线 |
| 缩放/平移 | 滚轮 / 拖空白 |
| 重置视角 | 双击空白 |
| 设置 | 右上角设置按钮 |
| AI 整理书签 | 设置 → 智能整理 |

## 开发

```bash
npm install           # Node.js 22.12+，使用 package-lock.json 安装依赖
npm run dev          # Vite 预览，使用 mock 数据
npm run typecheck    # TypeScript 检查
npm run check:ui     # 禁止业务界面使用原生下拉框
npm test             # Vitest
npm run build        # 构建 dist/
npm run check        # check:ui + typecheck + test + build
```

## 安装到 Chrome

1. `npm run build`
2. 打开 `chrome://extensions`
3. 启用“开发者模式”
4. 选择“加载已解压的扩展程序”
5. 选择项目里的 `dist/`
6. 打开新标签页

已有安装需在扩展管理页点击“重新加载”，再打开新标签页。工具栏收藏弹窗和专用收件箱入口已移除；旧版本创建的书签文件夹和书签保留，可继续在图谱或 Chrome 书签管理器中管理。

## 打包

```bash
npm run package:extension
```

脚本会先构建 `dist/`，再生成：

```text
release/loci-0.1.3.zip
```

这个 zip 可用于备份、分发测试或作为 Chrome Web Store 上传前的本地包。

0.1.3 的商店文案、权限理由与审核说明见 [上传指南](docs/chrome-store/0.1.3/UPLOAD-GUIDE.txt)。截图和宣传图保存在本机 `release/chrome-store-0.1.3/`，完整素材包为 `release/loci-0.1.3-store-assets.zip`。

## 权限说明

| 权限 | 用途 |
| ---- | ---- |
| `bookmarks` | 读写 Chrome 书签和分组 |
| `history` | 聚合访问频次和最近访问 |
| `topSites` | 书签为空时显示常用站点 |
| `storage` | 保存设置、连线、图钉、待办和天气缓存 |
| Open-Meteo 两个域名（可选） | 用户启用天气时申请，用于城市搜索和预报 |
| `geolocation` | 点击“使用当前位置”时进行一次定位以选择天气城市 |
| BigDataCloud 域名（可选） | 用户点击定位时申请，将坐标识别为城市 |
| gstatic.cn 图标域名（可选） | 开启图标缓存时申请，用于将图标下载到本机 |
| Tushare 域名（可选） | 用户主动连接行情服务时申请，用自备 Token 查询指数、股票和交易日 |

隐私说明见 [docs/PRIVACY.md](docs/PRIVACY.md)。

## 天气服务与验证

天气由 [Open-Meteo](https://open-meteo.com/) 提供。免费端点面向非商业用途；商业化分发前需按实际用途核对[服务方案](https://open-meteo.com/en/pricing)。新用户默认不启用天气，不自动定位，只有选择城市后才查询预报。

当前已验证开发预览中的真实城市搜索、预报、待办跨标签页同步，以及类型检查、自动化测试和构建。Chrome 扩展实装后的可选权限弹窗、拒绝/撤回权限流程仍需人工验收。
